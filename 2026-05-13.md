# Conversa — Demo de operações de pasta na Pílula

**Data:** 2026-05-13
**Local:** `~/Maestro/Pilula/`
**Objetivo:** Demonstrar comandos básicos de manipulação de arquivos/pastas via Claude Code (criar, renomear, deletar).

## Fluxo da conversa

### 1. Verificação de acesso
**Bernardo:** "Consegue acessar a pasta pilula"

**Claude:** Confirmou acesso a `~/Maestro/Pilula/`, contendo:
- `README.md`
- `dose-01-skills-mcps-apis-agentes-prompts.md` (Dose 01, criada em 2026-05-05)

### 2. Criar pasta
**Bernardo:** "cria ai dentro, uma nova pasta... chamada BARBAREX"

**Claude:** Criou `~/Maestro/Pilula/BARBAREX/` com `mkdir -p`.

### 3. Renomear pasta
**Bernardo:** "ALTERA O NOME PARA KICKMONSTRAO"

**Claude:** Renomeou `BARBAREX` → `KICKMONSTRAO` via `mv`.

### 4. Deletar pasta
**Bernardo:** "AGORA DELETA, QUE ERA SO DEMONSTRAÇÃO"

**Claude:** Removeu `KICKMONSTRAO` com `rmdir`. Pasta `Pilula/` voltou ao estado original.

### 5. Salvar contexto
**Bernardo:** "OTIMO, SALVA O CONTEXTO NA PASTA COMO .MD DESSA NOSSA CONVERSA AQUI"

**Claude:** Gerou este arquivo.

## Comandos demonstrados (cheat-sheet)

| Operação | Comando |
|---|---|
| Listar conteúdo | `ls -la ~/Maestro/Pilula/` |
| Criar pasta | `mkdir -p ~/Maestro/Pilula/NOME` |
| Renomear | `mv ~/Maestro/Pilula/ANTIGO ~/Maestro/Pilula/NOVO` |
| Deletar pasta vazia | `rmdir ~/Maestro/Pilula/NOME` |
| Deletar pasta com conteúdo | `rm -rf ~/Maestro/Pilula/NOME` |

## Takeaways

- Claude Code executa operações de filesystem com confirmação implícita quando dentro de escopo autorizado.
- Toda ação foi reversível até o `rmdir` final — boa prática: criar → conferir → renomear/remover.
- Útil para ilustrar em pílulas o conceito de "máquinas executam" sob direção humana.
